# Todo App

A small full-stack Todo/Tasks app built to explore [Claude Code](https://claude.com/claude-code) and its abilities as a coding assistant — from scaffolding a project through building out real features.

The app itself is a simple task manager, used here as a practice ground for:

- A **React** frontend (Vite), with **TailwindCSS** and light/dark mode support planned
- An **Express.js** backend
- **MongoDB** as the database

## Project structure

- `client/` — React frontend (Vite)
- `server/` — Express.js backend
- MongoDB — not set up yet

## Getting started

### Client

```bash
cd client
npm install
npm run dev
```

### Server

```bash
cd server
npm install
npm run dev
```

## Status

Project scaffolding only — no Todo functionality, styling, or database wired up yet. More to come as the project grows.
